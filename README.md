# MusicGallery

**An evolving Android music + podcast player by Pratyush.**

MusicGallery is being rebuilt from its original offline music-player release into a modern, Android-native listening experience with music and podcasts in one app.

> **Built by Pratyush**

## Current version

### V3.1 — First genuinely usable release

**Status:** Active alpha development  
**Version:** `3.1.0-alpha01`  
**Minimum Android:** 9 / API 28+

V3.1 is the first release line being developed as a genuinely usable product rather than a prototype. It is built to be installed, tested, improved, and versioned continuously.

Go to the **`v3.1` branch** to see the current source.

## Release policy

Every installable release receives a unique version name and monotonically increasing version code. Development builds use alpha/beta identifiers when appropriate.

Examples:

```text
3.1.0-alpha01
3.1.0-alpha02
3.1.0-beta01
3.1.0
3.2.0
```

No release version will silently replace another. Each meaningful release should have its own release notes and APK asset.
