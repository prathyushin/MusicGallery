# MusicGallery Changelog

## 4.0.0-alpha01

### V4 foundation
- Created as a new version branch: `v4.0.0-alpha01` from the V3.1 baseline.
- Android 9 / API 28 remains the minimum supported platform.
- Version code: `40`.
- Playback client now targets the dedicated `MediaSessionService` instead of creating a player inside the Activity.
- Background playback architecture is now the V4 direction.
- Release workflow builds an installable APK and publishes it as a GitHub prerelease.
- Product direction follows the V4 Grand-Scale Product Blueprint: local-first music, first-class podcasts, persistent playback context, premium Material 3 UX and privacy-first operation.

### Release scope
This is an alpha engineering release. It establishes the V4 product line and installable build pipeline; it does not claim that every V4 roadmap feature is complete.
